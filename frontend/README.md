# Frontend

React + Vite + Tailwind CSS + shadcn/ui.

Animation libraries installed for the product UI:

- `framer-motion` — component transitions
- `gsap` — timeline and scroll motion
- `lottie-react` — vector animations
- `@tsparticles/react` and `@tsparticles/slim` — particle fields

Re-exports live in `src/lib/animation.ts`.

```powershell
npm install
npm run dev
```

The app runs at http://localhost:5173. See the repository README for the full stack.
